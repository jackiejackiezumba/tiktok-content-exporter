Privacy Policy

Last updated: October 15, 2026

This policy explains how TikTok Content Exporter handles information when users use the application.

1. Information accessed

With the user's authorization, the application may access TikTok account information and available video metadata and metrics permitted by the granted API scopes.

2. Purpose of use

Information is used to display video data, let users select videos, and export selected data to spreadsheet files.

3. Storage and sharing

The application is intended to process data for the user's own reporting. Any actual storage, transmission, or sharing of data will depend on the implemented application features. Data will not be sold.

4. Account authorization

Users authorize access through TikTok's supported authorization process. Users can revoke access through the available TikTok account or application settings.

5. Security

Reasonable safeguards should be used to protect credentials and exported files. Users should not share access tokens or client secrets.

6. Data retention and deletion

Users should delete exported files they no longer need. Any application-side retention and deletion procedures will be documented as those features are implemented.

7. Contact

For privacy questions or data deletion requests, contact the application operator through the contact method provided with the application.
